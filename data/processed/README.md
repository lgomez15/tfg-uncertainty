### `usepu_assets_daily_features.csv`

- Frequency: Daily
- Rows: `2227`
- Columns: `29`
- Coverage: `2014-01-03` to `2023-11-13`
- Built by: `notebooks/cleaning_and_preparation/01_us_assets_cleaning_and_preparation.ipynb`

- Gold: OHLC + `Gold_Return`, `Gold_Vol7d`, `Gold_Vol30d`, `Gold_Vol90d`
- Bitcoin: OHLC + `BTC_Return`, `BTC_Vol7d`, `BTC_Vol30d`, `BTC_Vol90d`

Used in:

- `notebooks/training/01_us_epu_markets_dd.ipynb`

### `cepu_csi300_merged.csv`

- Frequency: Monthly
- Rows: `247`
- Columns: `17`
- Coverage: Monthly overlap between CEPU and CSI 300 (starts in 2005)
- Built by: `notebooks/cleaning_and_preparation/02_china_assets_cleaning_and_preparation.ipynb`

Core features:
- `CNEPU`, `ΔCNEPU`, `CNEPU_MA12`, `CNEPU_Std12`
- `CSI_Return`, `CSI_Vol`, `CSI_Vol3m`, `CSI_Vol6m`
- monthly OHLC aggregates and trading-day count

Used in:
- `notebooks/exploratory/merged/china_uncertainty_markets/`

## Expected Missing Values

NaN values are structural (rolling windows / differences):

- `usepu_assets_daily_features.csv`
	- first row for returns,
	- first 7 rows for 7-day volatility,
	- first 30 rows for 30-day rolling metrics,
	- first 90 rows for 90-day rolling volatility.

- `cepu_csi300_merged.csv`
	- first row for `ΔCNEPU`,
	- first 11 rows for 12-month CNEPU rolling metrics,
	- initial rows for `CSI_Vol3m` and `CSI_Vol6m`.
