# Datos procesados (series del análisis)

Series usadas en el TFG, generadas por
`notebooks/cleaning_and_preparation/03_unified_panels_2014_2025.ipynb`.
Periodo común para los dos países: **enero de 2014 a julio de 2025 (139 meses)**.
La volatilidad realizada mensual es la desviación típica de los rendimientos
logarítmicos diarios de cada mes (ecuación 2 del trabajo); los rendimientos son
logarítmicos (ecuación 1).

### `panel_usa_mensual.csv` (mensual)
- `date`: primer día del mes.
- `EPU`: índice de incertidumbre de EE. UU. (media mensual del índice diario).
- `vol_SP500`, `vol_Gold`, `vol_BTC`: volatilidad realizada mensual de cada activo.

### `panel_china_mensual.csv` (mensual)
- `date`: primer día del mes.
- `CNEPU`: índice de incertidumbre de China continental.
- `vol_CSI300`, `vol_Gold`, `vol_BTC`: volatilidad realizada mensual de cada activo.

### `rendimientos_mensuales.csv` (mensual)
- Índice `date` (mes) y columnas `SP500`, `CSI300`, `Gold`, `BTC`: rendimiento
  logarítmico mensual de cada activo (estadística descriptiva).

### `rendimientos_diarios.csv` (diario)
- Índice `date` (día) y columnas `SP500`, `CSI300`, `Gold`, `BTC`: rendimiento
  logarítmico diario de cada activo (base del modelo GARCH).

## Expected Missing Values

NaN values are structural (rolling windows / differences):

- `usepu_assets_daily_features.csv`
	- first row for returns,
	- first 7 rows for 7-day volatility,
	- first 30 rows for 30-day rolling metrics,
	- first 90 rows for 90-day rolling volatility.

- `cepu_csi300_merged.csv`
	- first row for `ΔCNEPU`,
	- first 11 rows for 12-month CNEPU rolling metrics,
	- initial rows for `CSI_Vol3m` and `CSI_Vol6m`.
